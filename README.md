# RP_2026_ENGINEER_ROBOT
## 一、代码理解
### 1. can发送都放在`sys_task.cpp`里面分id节点发送，除了达妙mit

### 2. 达妙mit的发送是在每个用到mit模式的组件自己的`.cpp`里面的

### 3. 整份工程中挺多电机都是未定义型号的(如4310等)，不影响功能，后续可以改改，在`mtr_common.hpp`里面定义一些电机

### 4.电机在线与离线是在`sys_task.cpp`中判定的

### 5.板通定义为设备，与图传和遥控器等同级，包含系统层和设备层，设备层管底层发送和解析，系统层管接收

### 6. 板通的包信息是在系统层中进行更新的，设备层只管发就完了

### 7.串口和can的时间戳`timestamp`都是在接收中更新的，串口用了lambda表达式，在init中绑定callback匿名函数

### 8.板通的数据更新其实发的是遥控器摇杆值

### 9. 摇杆值在遥控器的系统层已经经过归一处理，范围为±100

### 10. 由于需要对rm电机外的电机进行降频，因此在所有达妙电机mit的组件更新都用了分频器
